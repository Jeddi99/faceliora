ทั่วไป

ใครเป็นตัวสแกน ใครใช้โมเดล?

Faceliora Scan คือแอปสแกนบน iPhone ส่วน Faceliora Clinic คือโปรแกรมเดสก์ท็อปที่ใช้โมเดล 3D ที่เตรียมมา Faceliora App เป็นแอปบุคคลทั่วไปอีกผลิตภัณฑ์หนึ่ง

ลิงก์ไปคำถามนี้
ภาพจำลองบอกผลการรักษาได้หรือไม่?

ไม่ได้ เป็นภาพเพื่อสื่อสาร ไม่ใช่การวินิจฉัย การทำนาย หรือการรับประกันผล การตัดสินใจต้องอาศัยการประเมินของแพทย์

ลิงก์ไปคำถามนี้
ภาพจำลองแม่นยำแค่ไหน?

ภาพจำลองคำนวณจากรูปร่างผิวในสแกนของผู้รับคำปรึกษา และผลของการฉีดอิงค่าที่วัดในงานวิจัย ซึ่งเป็นค่าของกลุ่ม ไม่ใช่การทำนายผลของแต่ละคน สแกนเห็นเฉพาะผิวด้านนอก ไม่เห็นกล้ามเนื้อ ไขมัน หรือกระดูก ผลจริงจึงต่างจากภาพได้ ทุกภาพและไฟล์ที่ส่งออกมีลายน้ำว่าเป็นภาพจำลอง และตัวเลขทางการแพทย์ในเอกสารจะแสดงเมื่อแพทย์ยืนยันมาตราส่วนแล้ว

สำหรับคุณ

Faceliora Web เป็น 2D หรือ 3D?

เป็นการวิเคราะห์และจำลองภาพนิ่ง 2D มุมตรงและมุม 90° ไม่ใช่โมเดล 3D ที่หมุนได้

ลิงก์ไปคำถามนี้
Faceliora Web ใช้งานได้ที่ไหนตอนนี้?

ใช้งานบนเว็บไซต์ได้แล้ว ส่วนแอปมือถือกำลังพัฒนา ยังไม่แสดงปุ่มดาวน์โหลดจาก App Store หรือ Google Play

ลิงก์ไปคำถามนี้
นำภาพจาก Faceliora Web ไปปรึกษาคลินิกได้ไหม?

ได้ ใช้ภาพเป็นจุดเริ่มต้นของการพูดคุยกับคลินิกและแพทย์ ไม่ใช่ข้อสรุปแทนการตรวจ

ลิงก์ไปคำถามนี้
Faceliora Web ต่างจาก Faceliora Clinic อย่างไร?

Faceliora Web ใช้บนเว็บสำหรับทุกคนและทำงานกับภาพ 2D ส่วน Faceliora Clinic เป็นโปรแกรมสำหรับคลินิก ใช้สแกนใบหน้า 3D จำลองการฉีด ศัลยกรรม และร้อยไหม แล้วสรุปเป็นใบปรึกษา

สำหรับคลินิก

Faceliora Clinic คืออะไร?

Faceliora Clinic เป็นโปรแกรมจำลองใบหน้า 3D สำหรับคลินิกความงาม ใช้สแกนใบหน้าของผู้รับคำปรึกษาจำลองการฉีดฟิลเลอร์ โบท็อกซ์ ไขมัน ศัลยกรรม และร้อยไหม วิเคราะห์ผิว แล้วสรุปเป็นใบปรึกษา ภาพทั้งหมดเป็นภาพจำลองเพื่อการสื่อสาร ไม่ใช่การรับประกันผลการรักษา และไม่แทนการตรวจของแพทย์
