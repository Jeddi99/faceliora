1ก่อนปรึกษา

วิเคราะห์และจำลองใบหน้า เห็นทั้งหน้าตรงและด้านข้าง

สำหรับผู้ใช้งานทั่วไปที่อยากสำรวจใบหน้าและภาพจำลองหัตถการแบบ 2D ดูได้ทั้งมุมตรงและมุม 90° ทั้งสองมุมเป็นภาพ 2D ไม่ใช่โมเดล 3D ที่หมุนได้ AI วิเคราะห์ใบหน้า 51 จุด

  1. เริ่มบนเว็บเข้าใช้งาน Faceliora Web ผ่านเว็บไซต์
  2. วิเคราะห์และจำลองสำรวจใบหน้าและภาพจำลองหัตถการแบบ 2D
  3. ดูภาพทั้งสองมุมทบทวนมุมตรงและมุม 90° ให้เห็นรายละเอียดจากแต่ละด้าน
  • ระยะกล้องทำให้สัดส่วนในภาพดูต่างได้
  • เปรียบเทียบภาพด้วยบริบทของมุม แสง และต้นฉบับ
  • รูปสำหรับปรึกษาไม่ใช่การรับรองความเหมาะสมของหัตถการ
เตรียมภาพต้นฉบับก่อนปรึกษา

Faceliora Web เป็นภาพ 3D หรือไม่?

ไม่ใช่ ทั้งสองมุม (หน้าตรงและด้านข้าง) เป็นภาพ 2D แยกกัน ไม่ใช่โมเดล 3D ที่หมุนได้ การจำลองบนสแกนใบหน้า 3D เป็นงานของ Faceliora Clinic ซึ่งใช้ในคลินิก

2ระหว่างปรึกษา

นำไปประกอบการปรึกษา

ใช้ภาพเป็นจุดเริ่มต้นของบทสนทนา ไม่ใช่ข้อสรุปแทนแพทย์

สำรวจภาพจำลองเพื่อสื่อสารสิ่งที่สงสัย การประเมินและตัดสินใจทางการแพทย์ยังอยู่กับแพทย์

  • มีความเสี่ยงสำคัญและข้อจำกัดอะไรสำหรับฉันที่ภาพนี้ไม่ได้แสดง?
  • ผลแบบใดคาดหวังได้อย่างสมเหตุสมผล และอะไรไม่สามารถรับรองได้?
10 คำถามที่ควรถามแพทย์ก่อนทำหัตถการความงาม

สิ่งที่ภาพจำลองแสดงไม่ได้

  • ภาพจำลองไม่ใช่การวินิจฉัย การทำนาย หรือการรับประกันผลการรักษา
  • ภาพที่ปรับรูปทรงแล้วไม่ได้แสดงความเสี่ยง การตอบสนองของร่างกาย หรือสิ่งที่อาจเกิดขึ้นระหว่างพักฟื้น
  • ความเหมาะสม ความเสี่ยง และผลที่เป็นไปได้ต้องประเมินโดยแพทย์

นำภาพจาก Faceliora Web ไปปรึกษาคลินิกได้ไหม?

ได้ ใช้ภาพเป็นจุดเริ่มต้นของการพูดคุยกับคลินิกและแพทย์ ไม่ใช่ข้อสรุปแทนการตรวจ

3หลังปรึกษา

เก็บบันทึกให้แยกคำตอบออกจากความคาดหวัง

หลังปรึกษาแบ่งบันทึกเป็นสามช่อง: สิ่งที่แพทย์อธิบาย สิ่งที่คุณเข้าใจ และสิ่งที่ต้องถามเพิ่ม หากมีภาพประกอบ ให้ใส่วันที่และกำกับว่าเป็นต้นฉบับ ภาพอ้างอิง หรือภาพจำลอง การติดชื่อประเภทภาพช่วยป้องกันการอ่านผิดในภายหลัง

  • สิ่งที่แพทย์อธิบาย
  • สิ่งที่คุณเข้าใจ
  • สิ่งที่ต้องถามเพิ่ม

  • ใครเข้าถึงได้ และจำกัดสิทธิ์อย่างไร?
  • เก็บข้อมูลแต่ละประเภทนานเท่าใด และเพราะอะไร?
